# 🐻🐮 說走就走的熊牛旅

京都 × 名古屋｜2026/10/30–11/02｜四天三夜動畫旅行手帳。

主網站入口：[`index.html`](./index.html)。單檔 HTML，包含手繪 SVG 動畫、日期切換、36 個行程站點、地圖搜尋與待辦清單。無須後端伺服器。

## 網站發布

使用 GitHub Pages，進入 **Settings → Pages → Build and deployment**，在 **Source** 選擇 **Deploy from a branch**、**Branch** 選擇 **main**、**Folder** 選擇 **/(root)**，按 **Save**。

完成後，網站預期網址：<https://niloyby.github.io/niuniu-trip/>。

## 維護

修改 `index.html` 並提交到 `main` 後，GitHub Pages 會依設定自動更新網站。`README.md` 本身不會出現在網站頁面中。

> 注意：本儲存庫為 Public；行程資料對所有知道或找到網址的人開放。飯店、景點的時段仍需以最新公告為準。
