# 🌴 生77小隊

沖繩｜2026/11/19–11/24｜五人同行、六天五夜復古旅行桌面。

公開網站：https://niloyby.github.io/niuniu-trip/

## 行程資料

唯一行程來源為 `data/itinerary.json`；`days` 各站格式為 `["19:30", "那霸機場", "01:00"]`，依序為到達時間、地點與停留時長。
目前共 52 筆站點，完整保留提供的時間、名稱與順序，皆為日本當地時間。時間跨午夜會顯示「隔日」，仍歸在原行程日。

## 功能

五位編號卡通隊員搭乘沖繩小巴；輪流揮手、車輪轉動，點擊會出現五人點名彩蛋。保留日夜切換、搜尋、Google Maps、收藏、到訪章、六日紀念冊與準備清單。
收藏與到訪章依日期及站點區分；本次準備清單使用 `okinawa-squad-20261119-checks`，避免沿用舊旅程勾選。
記錄僅保存在目前瀏覽器，不跨裝置同步。

交通與住宿分頁只呈現本次提供的安排；未知航班與名護住宿標示待補充。
11/23 機場後接續北部景點的順序保留原樣，未推定為搭機離境。

## 發布與驗證

GitHub Pages 使用 main 根目錄，網址維持不變。
JavaScript 可用 `node --check assets/app.js` 與 `node --check assets/retro.js` 檢查。
以 HTTP 靜態頁面檢查六日切換、52 筆站點、跨午夜標示、收藏蓋章、路線、準備清單與日夜配色。

隊徽為 77，成員標記 01–05，集章格仍依六個旅行日區分；不使用真實成員姓名或肖像。動畫可透過既有開關停止，初次載入尊重減少動態效果設定。
