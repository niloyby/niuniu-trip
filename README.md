# 🐻🐧 熊企鵝遊

京都 × 名古屋｜2026/10/30–11/02｜四天三夜復古旅行桌面，保留小熊、企鵝與粉色列車。

**公開網站：** https://niloyby.github.io/niuniu-trip/

## 專案結構

```text
niuniu-trip/
├── index.html           # 網站視窗、分頁與手帳結構
├── assets/
│   ├── style.css        # 畫面、排版與動畫樣式
│   ├── app.js           # 日期切換、行程時間軸、動畫開關、清單功能
│   ├── retro.css        # 復古桌面、手機排版與日夜配色
│   └── retro.js         # 收藏、到訪章、紀念冊、路線圖與角色彩蛋
├── data/
│   └── itinerary.json   # 唯一行程資料來源（日期、40 個站點、提醒與準備清單）
└── README.md
```

## 後續修改行程

只需更改 `data/itinerary.json` 的 `days` 陣列內對應日期的 `stops`，每筆的欄位順序：

```json
["15:33", "清水寺", "01:00"]
```

代表「到達時間、地點名稱、停留時長（HH:MM）」。新增、刪除、排序站點均可直接編輯陣列。

`spots` 儲存針對特定地點的警示；`hints` 依 Day1～Day4 順序顯示當日提醒；`packing` 儲存準備清單。修改完畢，提交 GitHub `main` 分支就會觸發 GitHub Pages 發布。

## 測試方式

用 HTTP 靜態伺服器打開，例如 `python3 -m http.server 8000`，然後至 `http://localhost:8000/` 查看。請勿直接雙擊 `index.html` 以 `file://` 開啟，因為瀏覽器可能阻擋讀取 JSON。

檢查四天日期切換、全部 40 筆行程、Google 地圖按鈕、動畫開關、準備清單勾選與行動版排版。

## 吉祥物動畫

首頁 SVG 插畫位於 `index.html`，小熊揮手、粉色火車與企鵝探頭都採 CSS 動畫。企鵝目前只有頭部從右側車窗露出、伸出單側小翅膀揮手，不繪製身體或腳；對應動畫 `penguinHello` 在 `assets/style.css`。網站顯示名稱為「熊企鵝遊」，GitHub Pages 專案與網址仍沿用 `niuniu-trip`，避免舊分享連結失效。


## 復古旅行桌面（2026-11-05）

- 五個分頁：航班、行程、路線、準備、筆記。選單支援鍵盤左右鍵、Home 與 End。
- 行程可搜尋、收藏、篩選收藏，以及手動蓋到訪章；四日小護照顯示已收集站數。
- 路線頁按照 JSON 的原始順序呈現站點，為非地理比例示意圖；Google Maps 連結可查單一地點或規劃從上一站出發的交通。
- 點擊列車會出現熊企鵝對話與小愛心；動畫可關閉，初次載入尊重系統減少動態效果的設定。
- 日間／夜間模式可手動切換，並在這台裝置記住選擇。
- 無新增套件、外部字型、追蹤碼、API 金鑰或後端服務。GitHub Pages 網址與行程資料來源維持原樣。

收藏與到訪章使用 `bear-penguin-desktop-v1`；配色使用 `bear-penguin-theme`。既有 `bearcow-v3-checks` 與 `bearcow-v3-motion` 繼續沿用。所有記錄均存於瀏覽器 localStorage，不會跨裝置同步。若儲存遭到封鎖，收藏／蓋章仍可於當次使用，並顯示無法持久保存的提示。
